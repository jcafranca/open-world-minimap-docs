# Customising the art

Every built-in image can be replaced in the MiniMap's **Art** section:

- **Background** (circle) and **Background Rect** (square and rectangle, 9-sliced)
- **Player Arrow** and **View Cone**
- **Marker Icons**, one per marker type: Quest, NPC, Enemy, Teleport, Waypoint, Custom
- **Icon Set**, your own named icons (see [Markers](markers.md#your-own-icons-and-styles))
- **Map Shader**

Leave a slot empty to use the built-in art in `Resources/MiniMap`. GPS uses **Dot Sprite** for the route, the trail uses **Particle Texture**, and the pin dialog's types each take an **Icon** (see [Map pins](pins.md)).

All included art is original.
