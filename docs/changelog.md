# Support and changelog

## Support

Questions, bugs and feature requests: [open an issue](https://github.com/jcafranca/open-world-minimap-docs/issues) on this repository. Please include your Unity version, render pipeline and, if you can, a screenshot or a short video.

## Changelog

### 1.0.0
First release:
- Minimap: circle, square or rectangle; fixed or rotating; compass; smooth zoom.
- Fullscreen world map with pan, zoom, find-me button, coordinates and sharp area maps.
- GPS navigation on the NavMesh, across floors, following moving targets.
- Auto-travel with manual takeover, and a glowing particle trail.
- Map pins with an Add a pin dialog, saved between sessions.
- Interiors and multiple floors with floor badges.
- One-click scene scanner for large worlds with LODs and terrain trees.
- Touch, controller and safe-area support; Built-in, URP and HDRP.
